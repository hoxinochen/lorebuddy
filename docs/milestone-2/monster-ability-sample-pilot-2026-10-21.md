## 范围

1. 食人魔巨棒：专属攻击参数与固定伤害／掷骰选项。
2. 狼啃咬：体型条件、倒地；纳入集群战术的必要上下文。
3. 眼魔麻痹射线：父级眼波射线限制、重复豁免、麻痹—失能—专注关系。
4. 吸血鬼魅惑：引用魅惑类人及局部修改，保留啃咬关联的必要原文。
5. 魔法师护身魔法：共享资源、反应规则，引用护盾术／法术反制及施法属性上下文。
6. 夺心魔触须→采脑：施加来源、前提、结束关系及豁免成功仍可能致死。

怪物输入限冻结 M1-C3 的 MM2025 候选来源；共享状态、法术及通用机制使用各自 PHB2024／MM2025 来源。出版身份 claimed、译文权威及再分发权 unknown 保留。所有新表达为 candidate／draft，不生成正式 Knowledge Node 或正式 Terminal 准入包。

本批是当前 M2 的有限补充试验，不变更整体 Exit Gate，不授权全书转换、自动执行、正式 Schema 实施、Terminal 修改、公开发布、Commit 或 Push。现有封闭 Rule Assertion Schema 不加字段；结构化语义放独立伴随草案。

## 本批制作与复核

用户直接要求本会话生成六项样本，因此本批由 Codex 编制，不冒充 Antigravity 交付，既有外部生产分工不作总体变更。程序核查来源、摘要、范围、引用闭合、跨视图一致及确定性；Codex 对照原文核查语义。制作与本地复核由同一主 agent 完成的限制如实记录，不称为独立人工内容验收；独立 Luna 答题不代替规则批准。

每项交付原文证据、结构化伴随草案、人类阅读卡、用途／依赖说明及 AI 消费材料。仅支持约定能力，不标成六只完整怪物，不展开眼魔全部随机射线、吸血鬼全部形态或完整怪物数据库。

## 模型试验

调用标识 gpt-6-luna，medium 为主、high 为对照。用户已另行明确允许独立子 agent。冷启动子 agent 不继承对话历史，答题只读取冻结材料及公开问题，不提供金标准；记录配置身份与工具回执，不把配置等同独立后端认证。

计划每份 36 题：六项能力各六题，包含正常使用、边界、错误主张、版本不匹配、缺少运行输入与缺少内容依据。主材料为结构化草案＋完整相关原文＋类型明确的证据；增加来源原文视图的 medium 探索性对照。题库与金标准先冻结，所有首次回答保留；若修包／改题，使用新修订并单列结果。

分别评分 result 字段、自然语言正文、状态一致性、证据标识能否解析与能否支持结论；程序按证据标识取原文，不让模型默写引文。缺资料／错版的正确保留计为处置正确，不能算作问题已由规则解决。

时间记录为整批 agent 调用耗时代理，首字延迟、单题用户路径、账单 token／费用不具备实测条件时记 unknown／Not Run。
