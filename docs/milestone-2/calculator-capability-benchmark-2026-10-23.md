# 计算器能力测试样本与比较口径

日期：2026-10-23。状态：**样本已准备，计算器测试未运行**。

用户批准生成纯能力测试题，复用历史LLM答卷作对照，不重新调用LLM；答案不得提供给计算器。本次不修改计算器、Terminal、平台Schema或Source，不生产正式规则卡、不构成M2 Exit。

## 1. 本轮交付及数据边界

工件位于 [`experiments/calculator-capability-benchmark/`](../../experiments/calculator-capability-benchmark/)。

| 文件 | 用途 | 是否交给计算器 |
|---|---|---|
| [input/questions.md](../../experiments/calculator-capability-benchmark/input/questions.md) | 16项自然语言题面，供阅读及核对 | 无需由核心读取自然语言 |
| [input/cases.json](../../experiments/calculator-capability-benchmark/input/cases.json) | 每题独立的request/context，只包含规则参数及现场输入 | **只传当前题request/context** |
| [input/evidence.json](../../experiments/calculator-capability-benchmark/input/evidence.json) | 9份原有证据记录，保留原ID、范围和来源指针 | 供核对映射，不要求核心解析原文 |
| [evaluator/gold.json](../../experiments/calculator-capability-benchmark/evaluator/gold.json) | 预期数值、阶段、状态及错误码 | **禁止提供** |
| [evaluator/historical-baseline.json](../../experiments/calculator-capability-benchmark/evaluator/historical-baseline.json) | 5道历史原题、原Gold及实际LLM答卷 | **禁止提供** |
| [evaluator/results-template.json](../../experiments/calculator-capability-benchmark/evaluator/results-template.json) | 待填实际输出、评分及耗时；当前均为空 | **禁止作为输入** |

目录分离是测试操作约定，不是沙箱隔离保证。执行端必须限制实际传入内容；评分发生在结果产生后。禁止把Gold、历史模型结论或计算器预先算出的结果加入context。能力的成功半伤条款、目标抗性与原始伤害是必要输入，不属于泄漏答案。

结构化输入沿用Buddy隔离核心的`calculate(request, context)`接口，不预设Terminal当前应用层也接收同一Envelope。未来测试Terminal时须先说明适配及未开放能力；尤其N08的关联减损数值不能被误报为Terminal已支持上限写入。

`prepare.py`只装配样本，不导入或运行计算器。输入文件写出后，才读取历史Gold和答卷，用于生成评分区。标准答案是对既有规则与原Gold的根AI复核，**不是独立人工验收**。D09旧答6/6保留为错误观察，正确预期仍为3/3；不把模型曾给出的任何答案自动升级为权威。

## 2. 16项样本覆盖

| 编号 | 内容 | 来源及比较资格 |
|---|---|---|
| N01–N03 | 2025幽魂的寒冷、魔法挥砍、非魔法挥砍 | 六卡批次V01的3个数值子项 |
| N04 | 火元素受到魔法挥砍11 | Luna high事实优先批次E06的数值子项 |
| N05 | 绿蟾豁免失败后受到火焰28 | 六卡回归G14的第①项 |
| N06–N07 | 绿蟾受到闪电31、力场31 | 六卡回归R02的2个数值子项 |
| N08 | 汲命之吻成功豁免＋心灵抗性 | 六卡D09的伤害和关联上限减损子项；保留历史失败 |
| B01–B03 | 2014幽魂的3种对应伤害 | 同一V01的版本边界；当前2024 Profile应拒绝，不算数值答对 |
| B04 | 缺少豁免结果 | 新增缺输入探针，无历史同题LLM对照 |
| B05 | 防御完整性未知 | 新增缺输入探针，无历史同题LLM对照 |
| B06 | 额外固定减伤未被支持 | 新增机制边界探针，无历史同题LLM对照 |
| B07 | 一次事件包含两种伤害 | 合成接口探针，不宣称汲命之吻有此规则 |
| B08 | 将处理后的伤害当原始伤害输入 | 新增输入口径探针，无历史同题LLM对照 |

这是5道历史题的**8个可计算数值投影＋8个边界请求**，不是16道独立历史LLM问答。未为扩大数字而把再生、长休恢复、附身、法术读取或状态施加等问题装扮成当前伤害计算能力。N08只输出关联减损数值，不执行最大HP写入。

绿蟾的“豁免已失败”保留在题面；输入流程承接已经确定的原始伤害，定义中`save=false`表示**此局部流程不再处理一次豁免**，不表示原法术没有豁免。魔法抗性的豁免优势也不转成数值减伤。

2014题保留独立环境标识，不为通过测试改用2024 Profile。B03的条件抗性已经按题设非魔法攻击局部求值，但仍不授权跨版本执行。B05的空防御数组只是未知场景占位，完整性标志为unknown，不能当作已知没有抗性。

## 3. 准确率如何比较

后续只运行待测计算器，不再跑一次LLM。先保存逐题原始结果，再读取评分区。结果缺失、异常、超时或重复题号应显式记失败，不删题；未运行则记Not Run。

分别报告：

1. **数值正确率，分母8**：N01–N08。最终伤害、关联减损及各阶段必须同时符合Gold，不能只看最后数字。另列“仅最终数值正确率”，避免与历史LLM未逐阶段作答的结果混淆。
2. **边界处理正确率，分母8**：B01–B08。状态与必要错误码符合预期，且不能返回可应用的伤害/减损数值。不得把正确拒算宣传为已会计算该规则。
3. **本组数值覆盖率**：11个有历史数值答案的子情形中，当前范围计划支持8个，2014的3个不支持。是否实际达到8/11待运行确认；不能仅因拒算正确就隐去覆盖缺口。

历史答卷仅比较相同数值子项。根AI复核的旧答投影为7/8：D09错误，其余所选子项正确。这是**筛选子集的描述**，不是重新估计Luna high总体正确率。V01拆出3项、R02拆出2项，彼此相关，不能当8次独立实验；同时按原题保留分组展示。E06来自另一批历史执行，须保留批次，不伪装成同一次跑分。

当前每项request/context由根AI按规则和题面预先装配。因此未来分数证明的是“**已提供正确结构化输入时，核心的能力**”，不证明自然语言理解、LLM选式/传参或整个助手已经同等正确。输入人工映射及核查成本另列为准备工作，不藏进零成本宣称。

## 4. 响应时间口径

所有耗时当前为null，尚未测量。后续执行时固定实现路径/源码修订、运行环境、时间单位、输入文件和计时范围，不在遇到失败后修改题目或核心再覆盖首次结果。

建议对每题记录：

- **新进程首次调用**：模块预先导入后，用单调时钟包住一次`calculate(request, context)`；每题使用新进程，不把前题预热混入冷首次调用。它不等于页面冷启动。
- **预热调用**：相同题先预热100次，再采样1,000次，原始样本、p50/p95和采样次数保留；计时不含Gold读取和评分，也不含磁盘写出。过小的耗时须注明计时噪声，不把小数位当精度保证。
- **如测完整入口**：另记输入装配→核心→格式化结果的总时间；网页按钮→预览绘制属于独立端到端指标，本轮样本本身未覆盖UI。

历史LLM日志只记录多题批次的完整执行时间，包含读材料、工具及写答卷。没有可用的同题单次API响应时间或首字时间，不能除以题数，也不能拿它与核心毫秒时间计算“快多少倍”。可以并列展示，但必须注明不同口径。若未来需要严格的同题端到端速度比，需另行获得相同计时边界的数据；本轮不为此新增模型调用。

## 5. 方案选择与停止点

选择“历史数值投影＋独立边界探针”，因为可保留真实失败与可追溯的对照，又不要求小核心理解整道自然语言综合题。

替代方案是把原30题全交给核心；目前大量题属于条件判定、状态或来源推理，会把“不在职责内”混成算术错误。另一替代方案是只用既有合成单元测试；它适合回归，但不足以展示真实候选卡如何映射到计算输入。本组采取有限真实映射，并明示人工装配边界，不扩充执行器。

这批是研究fixture，局部标识不作为正式知识ID或新Schema；映射修订仅为本次说明，不迁移或修改旧候选卡、Source或历史答卷。继承的来源出版身份仍claimed，译文权威/权利unknown；内部研究文件不代表公开再分发许可。保留必要来源指针和单份当前样本，不增加每次变更归档或新摘要门禁。

本轮停止于样本生成、来源映射与隔离检查。**计算器正确率与响应时间均Not Run**；没有调用新模型，没有修改Terminal，也不因样本准备完成自动修改计算器实现。

准备检查已通过：16项ID唯一、8＋8分组闭合；9份复制证据与原记录及文本摘要一致；5份历史答卷逐条保持原样；request/context没有预期输出字段；实际结果、分数和耗时槽位仍为空。该检查只证明材料装配符合本约定，不等于核心通过能力测试。
