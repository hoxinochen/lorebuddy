# 决定性事实先行：Prompt对照约定

2026-10-22，用户批准尝试“一次回答内先列决定性事实，再给结论”。本轮仅测试消费者Prompt，不改7张候选卡、原文、采用、Schema或Terminal，不实施检查器，不新增怪物，不转正。

## 设计与固定范围

为什么：完整材料已送达，Luna medium仍在浴血比较和绿蟾防御应用上不一致。通过输出实际输入、比较和适用效果，让决定性依据先于结论可见；不要求内部思维链。替代方案是继续扩写卡、逐题投料、第二次完整复核或升模；这些改变事实/材料范围或调用成本，不能隔离本轮Prompt效果，暂不采用。

沿用上轮优化侧3组完整材料，复制分块字节不变。24道原题保持措辞与顺序，每组末尾再加2道预先固定的新数值/对象变式，共30题。基线沿用原回答要求；实验侧只追加一个通用输出契约：“事实→适用与核对→结论”，要求实际比较式、相关防御和分量计算。两方题目、材料、JSON字段及通常100–250字目标相同；无答案示例，无针对某题的失败提示或正确数值暗示。

两轮独立首答，每轮两方各3组、每组10题；12次gpt-6-luna medium调用，共120份答案，全部计划及Gold在第一次派发前固定。不调用high或6.1，不作二次答案复核，不因失败追加重复。子agent仅允许读取计划白名单、禁止Gold/历史答案/报告/记忆和联网；完整工具返回逐字审计。

通用Prompt允许核对所选卡防御，但不直接告诉某题哪项防御适用。要求公开简短事实、计算及规则依据，不要求记录模型内部思考。官方一般建议采用直接指令、明确输出约束、不索取内部思维链；这不是Luna特定效果保证：[OpenAI官方提示原则](https://developers.openai.com/api/docs/guides/reasoning-best-practices)。

## 评价与停止

根AI按固定来源及Gold评分，所问任一决定性结论或解释错误/自相矛盾即内容失败；状态、引用和事实先行格式另列。两处旧顽固题、其他24题回归、新6题、两次独立执行分别展示。对比全部回答而非只挑改善项；即使全对也只支持有限样本，不宣布稳定100%。若基线已全对或差距不一致，如实写无法证明增益。

记录实际完整执行耗时、输出量、日志tokens及缓存；不将批答时间除以题数当API延迟，不以工具循环累计tokens直接外推业务单价。不重新调查价格。本轮不修改候选事实、正式Schema或模型默认配置；Prompt为本地实验文本，不是生产接纳。对现有ID、版本、迁移及未来TRPG无变更。
